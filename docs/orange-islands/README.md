# Orange Islands exterior map design — first pass

Based on follower-port commit 2dc0f227cf31c01bce563d674b7fa31f7bb21e8c and the supplied region plan. Open the repository in Porymap and select gMapGroup_OrangeIslands.

| Map | Size | Design |
| --- | --- | --- |
| Valencia | 40×40 | Coastal settlement, lab garden, Center/Mart facades, residences, beach seating |
| Route 1 | 30×40 | Southern ferry beach, picnic furniture, long pier |
| Route 2 | 50×40 | Winding jungle trail, encounter clearings, pond, optional branches |
| Route 3 | 40×60 | Surf crossing, staggered reef banks, three optional rest islets |

Valencia connects south to Route 1 (offset +5), west to Route 2 (offset 0), and north to Route 3 (offset 0); each route has a reciprocal connection. Terrain and collision use the existing General + Orange Islands tilesets. Signs provide local directions. Roofs, palms, shrubs, signs and reef rocks block movement; paths and the pier are walkable. Route 3 requires Surf.

These are editable exterior designs, not a finished region. Building entrances remain blocked until interiors and warps are added. The pier has no ferry event yet. Trainers, encounters, item rewards, and the Surf acquisition sequence remain to be implemented. Route 3's northern landing is reserved for Mikan; the existing 20×20 Mikan placeholder is not connected yet. Route 4's western sea departure still needs integration. Regional map sections retain the existing placeholder; map-name popups are disabled on these four maps to avoid showing LITTLEROOT TOWN.

The layout header was regenerated by the repository build to include the ten previously missing layout IDs already present in layouts.json.

Validation: `python3 docs/orange-islands/validate_maps.py` checks map-buffer limits, binary sizes, metatile IDs, reachable landmarks/signs, and reciprocal connection seams. `source /workspace/.setup-cache/activate.sh && make -j5` builds the ROM in the prepared cloud environment. Emulator traversal and visual review in Porymap remain necessary; the reachability check does not emulate Surf mounting, followers or event execution.

PNG previews accompany the source maps. They render the actual existing tiles/metatiles with static animation frames.
